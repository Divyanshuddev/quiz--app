# 🎯 Quiz App  

A dynamic quiz application built with **React.js** that fetches questions from the **Open Trivia Database API**. Test your knowledge and see your score in real time!  

## 🔹 Features  
- Multiple-choice questions with instant feedback  
- Score tracking & results summary  
- Responsive design (works on mobile & desktop)  
- Smooth UI with transitions  

## 🔹 Tech Stack  
- React.js (Vite)  
- CSS  
- Typescript
- Material UI
